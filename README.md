# New Coastal K9 and Pest Solutions website (preview)

A separate, static version of the CK9PS website. It lives on its own branch,
`new-ck9ps-site`, and has nothing in common with the `main` branch that runs ck9ps.com.

**Do not merge this branch into main.** That would replace the live site.

- Pages are generated by `build.py` into `site/`. Edit `build.py`, then run `python3 build.py`.
- Vercel serves the `site/` folder as is (see `vercel.json`).
- Pages are set to `noindex` until the site is ready to go live.
